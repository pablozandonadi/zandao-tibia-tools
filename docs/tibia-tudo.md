# Tibia Tudo

Nome visível, ícone Windows e marca do menu atualizados. Identidades de atualização, executáveis e pasta de dados foram preservados para compatibilidade.

Menu: animação apenas em hover/foco, respeitando movimento reduzido. Cubo e café usam GIF no hover; ícone Windows usa imagem estática.

O usuário autorizou a divulgação do Pix de apoio com chave aleatória; o QR Code é gerado localmente a partir do código fornecido e seu CRC foi validado.

Sprites selecionados pelo usuário: Dice de Lupus Aurelius e Coffee de Makadamia, https://www.tibiafanart.com/players-sprites/. Permissão de uso comercial ainda não verificada.
