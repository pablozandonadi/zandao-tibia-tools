## Novidades

- World Board manual: cole o Server Log, confira as mudanças reconhecidas e salve por personagem, mundo e dia no perfil local.
- Yasir manual: presença pela mensagem Oriental Trader; ausência somente com cópia completa e todas as linhas reconhecidas. Registros vencem no próximo server save.
- Gerar mensagem do dia: calendário, Rashid, boostados, Dream Court e mudanças observadas, com texto editável e botão Copiar mensagem.
- Campos manuais para comunidade, assinatura, Deeplings, região, Roshamuul e Tibia Coin; dados desconhecidos ficam com ❓. Tibia Drome usa o calendário quando disponível.
- Registros entram no backup do usuário e são excluídos dos pacotes distribuídos. Não existe compartilhamento automático entre computadores.
