Hunt Analyser

Com o programa aberto, clique em Copy no Tibia no Party Hunt Analyser, no Hunting Analyser e no Input Analyser (Received Damage), um depois do outro, e depois em Colar do Tibia: os 3 cards são preenchidos de uma vez (o app guarda cada cópia e reconhece qual é qual). Também dá para colar direto nas caixas (Ctrl+V). A hunt só vai para o Histórico quando você clicar em 💾 Salvar.

Histórico de hunts

Cada análise do Hunt Analyser (loot split + dano) fica salva aqui, só neste computador, em historico_hunts.json. Para levar para outro PC ou mandar para alguém, use Exportar; quem recebe usa Importar.

Ferramentas

🤝 Shared XP

Digite um level para ver a faixa, ou os levels da party para saber se o shared funciona.

Regra do Tibia: o maior level pode ser no máximo 3/2 do menor. Além disso, todos precisam estar atacando ou curando e perto do líder. No Hunt Analyser, o botão 🤝 Verificar shared confere a party com os levels de agora no tibia.com.

📈 Quando eu upo?

A XP/h vem da média das suas hunts salvas desse personagem (com o Hunting Analyser colado). Sem a XP atual, o app usa o level de agora no tibia.com (início do level).

Organizar prints

Separa as screenshots do Tibia em Personagem / Tipo (e por mês, se quiser). Prints que já foram organizados não são copiados de novo.

Pronto para organizar.

Timers de áudio

Aperte a tecla do timer no Tibia e ele começa a contar; quando acaba, toca o som. Funciona com o app minimizado. O app só confere as teclas que você cadastrou aqui: não grava o que você digita e não manda tecla nenhuma para o jogo.

▬ Barra no Tibia

Vale para os timers com "Barra no Tibia" ligada. Mexa nos controles com o Tibia aberto: as barras de exemplo aparecem em cima dele para você ajustar. A posição é em % da janela do Tibia.

Configurações

👤 Meus personagens

O app confere cada personagem no tibia.com (nome, level, vocação e mundo). O escolhido em Usar é o "Seu personagem" do Hunt Analyser.

💾 Backup de tudo

Guarda num arquivo só tudo o que é seu, para levar para outro PC ou não perder nada:

  • Histórico de hunts (com as transferências pagas)
  • Meus personagens
  • Embuimentos: preços, o que você já tem e os escolhidos
  • Prints: pastas e opções
  • Janela: fixar por cima e transparência
  • Timers de áudio (os arquivos de som importados não entram)

Para mandar só algumas hunts para um amigo, use Exportar/Importar na aba Histórico.
