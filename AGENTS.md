# Fluxo compartilhado do ZandaoTools

Esta pasta é a fonte compartilhada entre Codex, Claude e o usuário. Preserve alterações em andamento de outros agentes. Não troque a branch nem resete o checkout compartilhado sem combinar; publique usando uma cópia temporária quando necessário.

Leia docs/pipeline-beta.md antes de alterar compilação, atualização ou publicação. Código e documentação devem permanecer acessíveis aos dois assistentes. Dados pessoais nunca entram em commits ou pacotes.

## Entrega obrigatória para análise

Por orientação permanente do usuário, ao concluir qualquer mudança no aplicativo, validar e publicar automaticamente a Beta oficial para análise, sem pedir novamente autorização. Commits e push em develop estão autorizados para preparar essa Beta. A entrega só termina após confirmar o pipeline e os artefatos disponíveis; informar a versão e o link da Beta.

Main e a versão estável só mudam após a verificação/aprovação do usuário. O clique consciente em “Publicar na versão original” na Beta é essa aprovação para promover aquela Beta específica, incluindo código, versão, instalador e portátil. Não publicar na estável automaticamente ao concluir mudanças. Preservar o checkout compartilhado, alterações de outros agentes e dados pessoais; publicar por uma cópia temporária, enviando somente arquivos necessários à mudança.
